# ИИ-инженер (AI Engineer)

Это специалист, который проектирует системы на основе готовых языковых моделей: собирает вокруг них инфраструктуру, пайплайны работы с данными, интеграции и инструменты оценки качества. 

# Задачи ИИ-асистента

В качестве источника данных для будущего ассистента возьмём документацию Ollama — опенсорс-инструмента для локального запуска языковых моделей.
Документация Ollama лежит в открытом доступе под MIT-лицензией, хорошо структурирована и охватывает все типичные ситуации, с которыми сталкивается RAG-система: описания API, FAQ, диагностика, инструкции по установке.
Ассистенту можно будет задать вопрос — например, «Какой HTTP-метод использует эндпоинт /api/generate?» или «Что делать, если модель не помещается в память?» — и получить корректный ответ, собранный по документации.

# Установка VS Code и расширения Python

1. Перейдите на официальный сайт. Выберите установщик для вашей ОС и скачайте его.
2. Запустите установщик и следуйте инструкциям. По завершении откройте VS Code.
3. Добавьте поддержку Python и Jupyter. Для этого откройте меню Extensions (иконка квадратов в боковой панели) и установите расширение Python от Microsoft.
4. После установки перезапустите VS Code. Теперь он готов к работе с проектами на Python.
