# Пояснения к словам иностранного происхождения
### Здесь собраны пояснения к словам иностранного происхождения, которые упоминаются в программах курсов линейки анализа данных, но пока не включены в словарную норму русского языка.
---
- A/B-тестирование — метод проверки гипотез, при котором сравнивают два варианта решения на разных группах пользователей.
- AB-тестирование — сравнение двух вариантов решения по заранее заданным метрикам на выборках пользователей.
- CLS-токен — специальный токен, который представляет весь текст.
- ETL-пайплайн — сокращение от Extract, Transform, Load; цепочка извлечения, преобразования и загрузки данных.
- F-строка — форматированная строка в Python, в которую можно подставлять значения переменных и выражений.
- K-близкий — относящийся к методу k ближайших соседей, где объект сравнивают с ближайшими примерами в данных.
- ML-пайплайн — сокращение от Machine Learning; последовательность этапов машинного обучения.
- NLP-пайплайн — сокращение от Natural Language Processing; цепочка обработки текста.
- Pet-проект — личный проект, который делается по собственной идее для практики и пополнения портфолио.
- T-тест — статистический метод, который помогает определить, является ли разница между средними значениями двух групп реальной или могла возникнуть случайно.
- Z-тест — статистический критерий для проверки гипотез, когда сравнение выполняется через нормальное распределение и Z-статистику.
- Агентный — связанный с ИИ-агентами: системами, которые выполняют задачи через последовательность действий и вызовов инструментов.
- Ансамблирование — подход в машинном обучении, при котором несколько моделей объединяют для повышения качества и устойчивости предсказаний.
- Аугментация — увеличение набора данных для обучения за счёт изменённых копий исходных примеров.
- Баг-трекер — система для регистрации, отслеживания и обработки ошибок в продукте.
- Батч — группа данных или задач, обрабатываемая одной порцией.
- Бустинг — метод машинного обучения, где модели обучаются последовательно и исправляют ошибки предыдущих моделей.
- Буткемп — интенсивный формат обучения, в котором участники за короткий срок осваивают практические навыки.
- Бутстрап — статистический метод оценки распределения показателя по многократным выборкам с возвращением из исходных данных.
- Бутстреп — статистический метод оценки распределения показателя по многократным выборкам с возвращением из исходных данных.
- Бэггинг — метод машинного обучения, при котором несколько моделей обучаются на разных случайно выбранных подвыборках данных, а затем их предсказания объединяются.
- Бэклог — упорядоченный список задач, требований или идей для дальнейшей работы.
- Вайбкодинг — подход к программированию, при котором разработчик описывает желаемое поведение программы ИИ-ассистенту и дорабатывает полученный код.
- Векторизация — преобразование объекта в числовое векторное представление.
- Воркшоп — практический семинар или тренинг с «hands-on» упражнениями для развития конкретных навыков.
- Геоаналитика — анализ данных с привязкой к географии: адресам, координатам, регионам или маршрутам.
- Геоданные — данные с географической привязкой, например координатами, адресами, регионами или зонами.
- Гиперпараметр — настраиваемый параметр, который задают до начала обучения модели.
- Датафрейм — табличная структура данных, которая используется для хранения, обработки и анализа строк и столбцов.
- Дашборд — приборная панель, визуальное представление ключевых показателей и событий в режиме реального времени.
- Дедупликация — удаление повторяющихся объектов из набора данных.
- Денормализация — намеренное добавление избыточности в структуру базы данных, чтобы упростить запросы или ускорить чтение данных.
- Деплоить — размещать новую версию приложения или сервиса в рабочей или тестовой среде.
- Деплой — развёртывание приложения, модели или сервиса в рабочей среде.
- Детекция — обнаружение.
- Джуниор — специалист начального уровня.
- Инференс — применение обученной модели к новым данным.
- Инференс-контур — часть системы, в которой обученная модель принимает входные данные и выдаёт результат в рабочем сценарии.
- Инхаус-стартап — внутренний стартап внутри компании, развиваемый силами собственной команды.
- Кастдев — исследование потребностей аудитории через интервью и проверку гипотез.
- Кастомный — сделанный на заказ или индивидуально настроенный.
- Контейнеризовать — упаковывать приложение и его зависимости в контейнер для воспроизводимого запуска в разных средах.
- Критерий Манна — Уитни — статистический критерий Манна — Уитни для сравнения двух независимых выборок.
- Лайфхак — практический приём или совет, который помогает упростить задачу.
- лемматизация — Приведение словоформ к их начальной словарной форме.
- Лид — многозначное слово. 1. Руководитель. 2. Потенциальный клиент, проявивший интерес к продукту или услуге.
- Лосс — численная мера ошибки модели: чем он больше, тем хуже предсказания, а при обучении модель старается его уменьшить.
- Мидл — специалист среднего уровня.
- Микросервис — отдельный небольшой сервис, который выполняет одну задачу и взаимодействует с другими сервисами.
- Микрофронтенд — часть пользовательского интерфейса, разрабатываемая как самостоятельный модуль.
- Мокап — реалистичный шаблон для демонстрации дизайна на носителях: упаковке, одежде, экранах, плакатах или других объектах.
- Мультииндекс — структура индекса с несколькими уровнями.
- Мультимодальность — способность системы работать с разными типами данных.
- Мэппинг — сопоставление объектов, данных или элементов между разными структурами.
- Оркестрация — координация сервисов через центральный процесс, который управляет порядком их работы.
- Оффер — предложение с описанием условий и ценности.
- Пайплайн — последовательность автоматизированных этапов обработки данных, кода, модели или контента.
- Парсинг — автоматический сбор и извлечение данных из источников по заданным правилам.
- Партиционирование — разделение данных на части по заданному правилу.
- Плейбук — документированная процедура или набор шагов для реагирования на типовой инцидент или ситуацию.
- ПМИ — сокращение, используемое в учебном контексте; требует проверки расшифровки перед добавлением в базу.
- Препроцессинг — предварительная обработка.
- Продакт — специалист, который отвечает за развитие продукта, его ценность для пользователей и приоритеты работ.
- Продакшен — многозначное слово. 1. Процесс производства продукта. 2. Рабочая среда, где модель, сервис или продукт используется реальными пользователями.
- Продакшн — относящийся к рабочей, промышленной среде продукта.
- Промптинг — составление запросов и инструкций для ИИ-сервиса.
- Прототипировать — создавать прототип.
- Пулинг — операция в нейросети, которая уменьшает размер представления данных и сохраняет важные признаки.
- Ревью — проверка или разбор работы.
- Ревьюер — специалист, который проверяет работу и даёт обратную связь.
- Свёрточный — связанный со свёрткой, операцией обработки данных, часто используемой в нейронных сетях.
- Скил — навык.
- Софт-скил — гибкий навык, то есть навык, связанный с коммуникацией, самоорганизацией или взаимодействием с людьми.
- Софтскил — гибкий навык, связанный с коммуникацией, командной работой, самоорганизацией и взаимодействием с заказчиками.
- Статтест — статистический тест.
- Стекинг — метод машинного обучения, при котором результаты нескольких моделей передаются другой модели для получения итогового прогноза.
- Стемминг — приведение слова к его основе для обработки текста, без обязательного получения его словарной формы.
- СТС — Сокращение от Connectionist Temporal Classification — «коннекционистская временная классификация»; метод обучения моделей распознавания последовательностей без заранее заданного соответствия между входными данными и результатом.
- Стэкинг — метод машинного обучения, где результаты нескольких моделей объединяются с помощью дополнительной модели.
- Сэмплирование — формирование выборки данных из более крупной совокупности для анализа, моделирования или проверки гипотез.
- Т-тест — статистический t-тест для проверки различий между средними значениями.
- Таймлайн — хронологическая последовательность событий.
- Телеком — сфера телекоммуникаций.
- Техдолг — накопленные технические проблемы или упрощения в системе, которые нужно исправить в будущем.
- Токенизация — разбиение текста на токены: слова, части слов или другие единицы.
- Токенизировать — разбить текст на токены.
- Трекер — инструмент или специалист, который помогает отслеживать прогресс, задачи и движение к цели.
- Фича — отдельная функция или возможность продукта для пользователя.
- Фреймворк — структурированный подход к решению задач.
- Хардскил — прикладной профессиональный навык, который можно проверить на задаче: владение инструментом, методом, технологией или техникой работы.
- Хэш — короткое вычисляемое представление данных.
- Эмбеддинг — векторное представление текста, изображения или другого объекта для машинного анализа.
- Юзабилити — удобство использования интерфейса или продукта.
- Юнит — минимальная самостоятельная часть программы, которую можно разрабатывать, проверять или запускать отдельно.
- Acceptance Testing — проверка, что система соответствует требованиям и готова к передаче заказчику.
- Ad hoc — разовая задача, решаемая без заранее заданного регулярного процесса.
- ADDR Process — процесс фиксации архитектурных или дизайн-решений, их причин и последствий для системы.
- Agile — гибкий подход к управлению проектами и разработке, основанный на коротких итерациях, быстрой обратной связи и регулярной адаптации планов.
- ALiBi — сокращение от Attention with Linear Biases; способ добавить позиционную информацию в механизм внимания трансформера.
- Alignment — настройка модели, при которой её ответы согласуют с ожидаемым поведением.
- ALS — сокращение от Alternating Least Squares; алгоритм, который по неполной таблице «пользователи × товары» находит скрытые предпочтения пользователей и признаки товаров, чтобы предсказывать рекомендации.
- API-First — подход к проектированию, при котором интерфейс API описывают и согласуют до основной разработки сервиса.
- ARPU — сокращение от Average Revenue Per User; средняя выручка на одного пользователя за выбранный период.
- AS IS — модель «как есть»: описание текущего состояния процесса или системы.
- Async API — интерфейс или спецификация для асинхронного обмена сообщениями между сервисами.
- Attention — механизм внимания в нейросетях.
- Audio — Звуковые данные или технологии их обработки.
- Audio Analysis — анализ аудио.
- Augmented Generation — генерация ответа моделью с использованием дополнительного внешнего контекста или данных, а не только ее внутренних знаний.
- Backward Pass — обратный проход.
- Baseline — базовое решение или модель, с которой сравнивают более сложные подходы.
- Batch Normalization — нормализация батча — небольшого пакета данных.
- Beam search — стратегия генерации, при которой модель удерживает несколько наиболее вероятных вариантов продолжения.
- BERT — сокращение от Bidirectional Encoder Representations from Transformers; архитектура языковой модели на основе трансформеров для понимания контекста текста.
- Best practice — проверенная практика, которая считается эффективной и рекомендуется для решения профессиональных задач.
- BI — сокращение от Business Intelligence; бизнес-аналитика: сбор, обработка и визуализация данных для управленческих решений.
- Bidirectional — двунаправленный подход в рекуррентных нейронных сетях, при котором модель учитывает контекст последовательности слева направо и справа налево.
- Bidirectional RNN — сокращение от Bidirectional Recurrent Neural Network; рекуррентная нейросеть, которая учитывает контекст последовательности в прямом и обратном направлениях.
- Big Data — большие данные: массивы данных большого объёма и сложности.
- BIO — схема разметки последовательностей: B отмечает начало сущности, I — её продолжение, O — текст вне сущности.
- BLEU — сокращение от Bilingual Evaluation Understudy; метрика оценки качества машинного перевода по совпадению фрагментов перевода с эталонным текстом.
- BPMN — сокращение от Business Process Model and Notation; стандартизированная нотация для описания и визуального моделирования бизнес-процессов.
- CAC — сокращение от Customer Acquisition Cost; стоимость привлечения клиента.
- Calendar Heatmap — календарная тепловая карта: визуализация, где значения показателя отображаются по датам с помощью цвета.
- Change Request — запрос на изменение: формальное описание нужной доработки.
- ChrF — метрика оценки качества машинного перевода на основе совпадений символьных n-грамм.
- Churn — доля пользователей или клиентов, которые перестали пользоваться продуктом за период.
- Churn rate — показатель оттока.
- Cloud — облачная инфраструктура или сервисы, предоставляемые через интернет.
- CMDB — сокращение от Configuration Management Database — база данных, в которой хранится информация о ресурсах организации, связанных с информационными технологиями (серверы, приложения, зависимости между ними).
- CNN — сокращение от Convolutional Neural Network; свёрточная нейронная сеть для обработки изображений и других данных с пространственной структурой.
- COMET — метрика для оценки качества машинного перевода, которая сравнивает перевод модели с эталоном.
- Computer Vision — компьютерное зрение.
- Constrained decoding — генерация текста с ограничениями.
- Context Learning — обучение или адаптация поведения модели по примерам и инструкциям, переданным в текущем контексте.
- Continuous batching — способ обработки запросов к модели, при котором новые запросы добавляются в пакет без ожидания завершения всех предыдущих.
- CoT — сокращение от Chain of Thought; подход, при котором модель выстраивает рассуждение по шагам.
- CTE — обобщённые табличные выражения.
- CTR — сокращение от Click-Through Rate; показатель кликабельности, доля пользователей, которые нажали на элемент.
- Customer Journey Map — карта пути клиента.
- CV — сокращение от Computer Vision; компьютерное зрение.
- Data Governance — управление данными.
- Data Lake — озеро данных; хранилище для больших объёмов структурированных и неструктурированных данных в исходном или близком к исходному виде.
- Data Operations — операции с данными.
- Data Science — область работы с данными, объединяющая статистику, программирование и методы машинного обучения для извлечения закономерностей и построения прогнозов.
- Data Warehouse — централизованное хранилище данных для аналитики и отчётности.
- Data-driven — основанный на данных и их анализе при принятии решений.
- Dataloader — компонент загрузки данных, который подаёт данные в модель партиями.
- Dataset — подготовленный набор данных.
- DAU — сокращение от Daily Active Users; количество уникальных активных пользователей за день.
- Decision Tree — алгоритм машинного обучения, который строит прогноз через дерево решений — последовательность правил и разветвлений.
- DEEP — мнемоника требований именно к продуктовому бэклогу: задачи детализируют вовремя, список развивается, элементы оценены и расставлены по приоритету.
- Deep Learning — раздел машинного обучения, основанный на многослойных нейронных сетях.
- Demo Lab — лабораторная среда для демонстрации атак и защиты, позволяющая практиковать навыки анализа без риска для боевых систем.
- Deployment — процесс развёртывания приложения или сервиса.
- DevOps — сокращение от Development and Operations — методология, объединяющая разработку и администрирование для ускорения цикла разработки и развёртывания.
- DL — сокращение от Deep Learning; глубокое обучение на нейросетевых моделях с несколькими слоями.
- Docker — платформа для упаковки и запуска приложений в изолированных контейнерах.
- Domain-Driven Design — подход к проектированию системы вокруг предметной области, её понятий и бизнес-правил.

- DS — сокращение от Data Science; область работы с данными, где применяют статистику, программирование и машинное обучение для анализа данных и построения моделей.
- DVC — сокращение от Data Version Control; система версионирования данных, моделей и экспериментов в проектах машинного обучения.
- E-commerce — электронная коммерция.
- EDA — сокращение от Exploratory Data Analysis; исследовательский анализ данных.
- EDR — сокращение от Endpoint Detection and Response — инструмент для обнаружения и реагирования на угрозы на конечных устройствах (компьютеры, серверы).

- IT — сокращение от Information Technology — информационные технологии.
- Job Stories — формат описания пользовательской потребности через ситуацию, мотивацию и ожидаемый результат.
- Junior — начальный профессиональный уровень специалиста.

- LLM — сокращение от Large Language Model; большая языковая модель, которая обрабатывает и генерирует текст.
- Lo-fi — сокращение от low fidelity; прототип низкой точности, который показывает структуру и логику интерфейса.
