# Установка Ollama: Linux, Windows и скачивание моделей

## Linux

1. Установите одной командой в терминале:
   `curl -fsSL https://ollama.com/install.sh | sh`
   Скрипт сам определит дистрибутив, поставит бинарник в `/usr/local/bin/ollama` и зарегистрирует службу systemd.
2. Включите и запустите службу:
   `sudo systemctl enable ollama && sudo systemctl start ollama`
3. Проверьте: `ollama --version` — если вернул номер, всё работает.

Для GPU-ускорения (NVIDIA/AMD) сначала поставьте проприетарные драйверы или ROCm — Ollama подхватит их автоматически.

## Windows

Два способа:
- **Графический**: скачайте `OllamaSetup.exe` с ollama.com → двойной клик → Install. Значок ламы появится в трее.
- **Одной командой** в PowerShell (администратор не обязателен):
  `irm https://ollama.com/install.ps1 | iex`
  Либо через winget: `winget install Ollama.Ollama`

Проверка — `ollama --version` в новом окне PowerShell. Требование: Windows 10 22H2 или новее; для NVIDIA — драйвер 551.61+.

## Как скачать модель

- `ollama pull <имя>` — просто загрузить модель на диск.
- `ollama run <имя>` — запустить диалог; если модели нет, она скачается сама.
- Имя и тег берите из каталога на ollama.com (страница модели → вкладка Tags). Пример: `ollama pull qwen2.5:7b-instruct-q4_KM`.

Полезные команды после установки:
- `ollama list` — что уже скачано;
- `ollama ps` — что загружено в память и как распределено между CPU/GPU;
- `ollama rm <модель>` — удалить с диска, освободить место.

Размер модели проверяйте до загрузки: 7–8B в кванте Q4 занимает 4–5 ГБ, кодовая 30B — около 19 ГБ только на диске. На 8–16 ГБ общей памяти начинайте с `:3b`/`:4b`, на 16 ГБ — с 7–8B.

Если доступ к ollama.com из РФ ограничен — настройте прокси/DNS до первого запуска, иначе модели не скачаются.
