# Руководство по файлу конфигурации Continue (.continue.yaml)

Ваш файл `/home/wirekit69/.continue.yaml` — это центральный узел управления для расширения **Continue** в вашей IDE. Он определяет, какие модели искусственного интеллекта доступны, как они работают и какие инструменты могут использовать.

Ниже представлено подробное описание структуры вашего файла и возможных дополнительных настроек.

---

## 1. Общая информация (Мета-данные)

```yaml
name: Python Coding (RTX 4050 - 6GB VRAM)
version: 0.0.1
schema: v1
```

*   **`name`**: Отображаемое имя вашей конфигурации. Помогает быстро понять, для какого стека или железа настроен профиль.
*   **`version`**: Версия самой конфигурации.
*   **`schema`**: Версия формата файла (актуально `v1`).

---

## 2. Секция `models` (Модели)

Это список доступных ИИ. Вы можете переключаться между ними в интерфейсе Continue. Каждая модель имеет свои роли и задачи.

### Основные параметры модели:
*   **`name`**: Имя, которое вы увидите в списке выбора.
*   **`provider`**: Источник модели (`ollama`, `openai`, `anthropic` и др.).
*   **`model`**: Техническое название модели.
*   **`apiBase`**: Адрес сервера, где запущена модель.
*   **`roles`**: Задачи, которые выполняет модель.
    *   `chat`: Общение в чате.
    *   `edit`: Генерация правок.
    *   `apply`: Применение изменений к файлам.
    *   `autocomplete`: Мгновенные подсказки при наборе (Tab).
*   **`capabilities`**: Дополнительные навыки.
    *   `tool_use`: Разрешает модели вызывать инструменты (поиск по коду, терминал).

### Анализ ваших моделей:
1.  **Локальные (Ollama)**:
    *   `qwen2.5-coder:7b`: Основная модель для чата и сложных правок. Работает на вашей видеокарте.
    *   `qwen2.5-coder:1.5b (Autocomplete)`: Легкая и быстрая модель для автодополнения кода "на лету".
2.  **GigaChat (через прокси)**:
    *   Модели `GigaChat-2` и `GigaChat-3` используют `provider: openai`, но обращаются к `http://localhost:8090`. Это означает, что у вас запущен локальный прокси-сервер, который перенаправляет запросы в GigaChat.
    *   У них закомментирован `contextLength`. Если раскомментировать (убрать `#`), можно будет загружать очень большие файлы (до 128к+ токенов).

## 3. Дополнительные настройки (Что еще бывает в файле)

Помимо `models`, файл поддерживает множество других секций для тонкой настройки.

### `tabAutocomplete` (Автодополнение)
Управляет поведением функции, предлагающей код во время печати.

```yaml
tabAutocomplete:
  enabled: true
  model: qwen2.5-coder:1.5b # Ссылка на имя модели из секции models
  maxTokens: 100
  debounceDelay: 200 # Задержка в мс перед показом подсказки
```

### `chat` (Настройки чата)
Определяет, какой контекст ИИ видит по умолчанию и как он показывает результат.

```yaml
chat:
  context:
    - code # Код из открытых файлов
    - docs # Документация
    - terminal # Вывод терминала
  defaultCompletionMode: diff # Показывать изменения в виде сравнения (diff)
```

### `prompts` (Пользовательские команды / Slash Commands)
Создание своих команд, начинающихся со слеша (например, `/test`, `/doc`). Очень полезно для рутинных задач.

```yaml
prompts:
  - name: testgen
    prompt: |
      Напиши unit-тесты для следующего Python кода, используя pytest.
      ```
      $SELECTED_CODE
      ```
```
*Использование: Выделяете код -> пишете `/testgen` в чате.*

### `modes` (Режимы работы)
Позволяет создать "личность" для ИИ под конкретную задачу.

```yaml
modes:
  - name: Reviewer
    role: >
      Ты — строгий senior-разработчик. Твоя задача — искать баги и нарушения стиля.
      Ты никогда не пишешь код, только критикуешь.
```

### `context` (Настройки извлечения контекста)
Как ассистент сам ищет релевантные куски кода в проекте, если вы ничего не выделили.

```yaml
context:
  code:
    maxItems: 10 # Сколько файлов добавить в контекст
    similarity: 0.8 # Насколько похожим должен быть код
```

### `systemPrompt` (Глобальная инструкция)
Текст, который добавляется в *каждый* запрос ко *всем* моделям.

```yaml
systemPrompt: |
  Ты работаешь в российском IT-проекте. Всегда используй русские комментарии в коде.
  Если пишешь Python, используй snake_case.
```

## Итог

Ваш текущий файл — это мощный "автопарк". Добавляя секции `prompts`, `modes` и `chat`, вы превращаете его в полноценного "второго пилота", который знает ваши привычки, умеет выполнять специфические команды и использует правильные инструменты для каждой задачи.
